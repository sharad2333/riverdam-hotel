# Riverdam Hotel — demo website

Simple beginner-friendly hotel website project for your portfolio.

Features
- Landing page with rooms
- Booking form (front-end) that saves bookings to localStorage
- Admin page to view and export bookings (password-protected in-browser prompt — demo only)

Tech
- Plain HTML / CSS / JavaScript
- Deploy easily with GitHub Pages

Quick start
1. Create a new GitHub repo (e.g. `riverdam-hotel`) and add these files.
2. Commit & push.
3. Enable Pages: Settings → Pages → branch `main` (or `gh-pages`) → Save. Your site will be at `https://<your-username>.github.io/<repo>/`
4. Open `admin.html` and enter the demo password `riverdam-admin` to view bookings.
